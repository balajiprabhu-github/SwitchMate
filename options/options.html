🧠 Local Gemini Nano LLM (On-Device AI)

SwitchMate uses Chrome's built-in Gemini Nano model via the Chrome Prompt API (window.ai / ai.languageModel) to run private, zero-latency inference directly on your laptop without cloud API keys.

To enable Gemini Nano in Google Chrome:

  1. Visit chrome://flags/#prompt-api-for-gemini-nano → select Enabled.
  2. Visit chrome://flags/#optimization-guide-on-device-model → select Enabled BypassPerfRequirement.
  3. Relaunch Chrome.
  4. Visit chrome://components/ → find Optimization Guide On Device Model → click Check for update to download weights.

Note: If Gemini Nano is not enabled, SwitchMate seamlessly falls back to smart local heuristics so you always stay protected!
